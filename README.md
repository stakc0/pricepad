# Pricepad clone

A high-fidelity capture of the public `pricepad.fun` marketing page, app route, docs route, styles, scripts, and public image assets.

## Routes

- `/`
- `/app`
- `/how-it-works`

The read-only `/api/paper` route proxies the public Pricepad paper-market data endpoint. Wallet signing and financial actions are not faked.
